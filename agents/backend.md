# Backend Agent

## Role

Own backend implementation work for Tutor Marketplace.

## Scope

- Spring Boot backend
- REST APIs
- application/service logic
- security integration
- persistence integration
- backend tests

## Rules

- Read relevant KB documentation and Jira ticket before implementation.
- Follow confirmed backend conventions.
- Do not invent API contracts, authorization rules, entities, or database fields.
- Coordinate schema changes with the Database Agent.
- Keep implementation consistent with the current source tree rather than assumed future architecture.
