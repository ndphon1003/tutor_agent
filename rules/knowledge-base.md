# Knowledge Base Rules

`tutor_kb` is the source of truth for confirmed project knowledge.

## Status handling

- **Confirmed**: safe to use as current project knowledge.
- **Planned**: intended direction; do not represent it as implemented/current fact.
- **TBD**: unresolved; requires investigation or a decision.

## Updates

Update the KB when work introduces or confirms durable knowledge about:

- architecture
- domain behavior
- API contracts
- database design
- product scope
- engineering conventions

Do not rewrite KB status merely to match an implementation that was created without an approved decision.
